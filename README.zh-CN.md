# CURE (学术论文引用检查工具)

[English](./README.md) | 中文版

**CURE** 是一个为研究人员和博士生设计的轻量级 Python 工具，用于自动检测“幽灵文献”——即列在了参考文献列表中，但在正文中从未被引用的条目。

## ❓ 为何选择 CURE？(适用场景)

在现代科研协作中，我们经常需要在不同文档格式间切换。虽然基于 Zotero 的纯 Markdown 或 LaTeX 工作流能保持完美的引用同步，但**使用 Microsoft Word 进行多人协作**时，频繁的修改和格式转换往往会导致引用链接断裂。

当你将 Word 或 PDF 初稿转换为 Markdown 进行最终汇总或提交时，引用会变成“静态文本”。在多轮迭代中，极易出现“正文段落已删、文末条目犹在”的情况。**CURE** 专项解决由于文档转换产生的“文献残留”问题，它通过语义特征匹配（而非软件内部链接）来确保文献的一致性。

## 🔄 推荐工作流

为了获得最佳效果，我们推荐针对不同输入格式的“从源文件到纯净版”工作流：

### 1. 格式转换
-   **针对 Word (`.docx`)**：使用 [Pandoc](https://pandoc.org/) 将其转换为 Markdown。
    ```bash
    pandoc your_paper.docx -o your_paper.md
    ```
-   **针对 PDF (`.pdf`)**：传统的 PDF 转换在处理复杂的学术排版时往往效果欠佳。我们推荐使用高质量的 OCR 工具，如 **[obsidian-marker](https://github.com/l3-n0x/obsidian-marker)**。它利用了 **[Mistral AI](https://mistral.ai/)** 强大的 OCR 能力，能在 PDF 转 Markdown 过程中完美保留文档的结构和语义。

### 2. 使用 CURE 进行清理
得到 `.md` 文件后，运行 **CURE** 识别并删除所有未引用的“幽灵文献”。

## 🚀 快速上手

### 安装

无需安装。只需下载 `check_uncited.py` 即可直接使用。

### 使用方法

在终端运行脚本，并指定你的 Markdown 文件：

```bash
python3 check_uncited.py -i "你的论文草稿.md"
```

### 命令行参数

| 缩写 | 全称 | 描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `-i` | `--input` | **(必填)** 待检测的 Markdown 文件路径。 | 无 |
| `-o` | `--output` | 结果报告的保存路径。 | `uncited_report.md` |
| `-h` | `--help` | 显示帮助信息。 | 无 |

## 📊 工作原理

CURE 不仅仅是简单的关键词搜索，它使用了 **启发式评分 (Heuristic Scoring)** 机制：
1.  程序扫描文档中所有可能的参考文献标题。
2.  通过检测标题后内容的“条目密度”（即有多少行看起来像参考文献）来对候选点进行评分。
3.  锁定真正的参考文献区，并提取每一条文献的“指纹”（作者姓氏 + 年份）。
4.  在正文区域进行跨行正则搜索，验证指纹是否存在。

## 📝 输出结果

工具会生成一份 Markdown 报告 (`uncited_report.md`)，详细列出所有未能匹配到引用的文献条目，并保留原文方便你对比查找。
