# CURE (学术论文引用检查工具)

[English](./README.md) | 中文版

**CURE** 是一个为研究人员和博士生设计的轻量级 Python 工具，用于自动检测“幽灵文献”——即列在了参考文献列表中，但在正文中从未被引用的条目。

## 🌟 功能特性

-   **中英文双语支持**：完美处理中英文学术文档。
-   **启发式智能切分**：采用启发式得分算法，精准定位参考文献区，有效避开目录（TOC）中的干扰。
-   **通用解析能力**：支持带序号（如 `[1]`, `1.`）和无序号（如 APA 样式的 `Aghion, P. (2013)`）的参考文献排版。
-   **模糊匹配算法**：支持跨行引用检测，以及多种引用习惯（如 `作者 et al., 2020` 或 `(作者A 和 作者B, 2020)`）。
-   **零依赖**：基于原生 Python 3 编写，无需安装任何第三方库。

## 🚀 快速上手

### 安装

无需安装。只需下载 `check_uncited.py` 即可直接使用。

### 使用方法

在终端运行脚本，并指定你的 Markdown 文件：

```bash
python3 check_uncited.py -i "你的论文草稿.md"
```

### 命令行参数

| 缩写 | 全称 | 描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `-i` | `--input` | **(必填)** 待检测的 Markdown 文件路径。 | 无 |
| `-o` | `--output` | 结果报告的保存路径。 | `uncited_report.md` |
| `-h` | `--help` | 显示帮助信息。 | 无 |

## 📊 工作原理

CURE 不仅仅是简单的关键词搜索，它使用了 **启发式评分 (Heuristic Scoring)** 机制：
1.  程序扫描文档中所有可能的参考文献标题。
2.  通过检测标题后内容的“条目密度”（即有多少行看起来像参考文献）来对候选点进行评分。
3.  锁定真正的参考文献区，并提取每一条文献的“指纹”（作者姓氏 + 年份）。
4.  在正文区域进行跨行正则搜索，验证指纹是否存在。

## 📝 输出结果

工具会生成一份 Markdown 报告 (`uncited_report.md`)，详细列出所有未能匹配到引用的文献条目，并保留原文方便你对比查找。
