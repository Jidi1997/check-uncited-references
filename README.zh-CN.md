# CURE (学术引用校验工具)

[English](./README.md) | 中文版

**CURE** (Check Uncited REferences) 是一款专为 **Markdown** 文档内核设计的轻量级 Python 脚本。由于 Markdown 文本具有高度的结构化特征，极易与各类 AI 工具产生深度联动，本工具旨在通过精准识别文末参考文献列表中的“冗余文献”/“幽灵文献”（即在正文论述中未被提及的文献条目），保障学术文档的严谨性。

---

Version 3.0 引入了显著的准确性与稳定性优化：

- **启发式年份提取**：针对“紧凑型”文献列表，通过启发式算法精准提取出版年份。

## ❓ 应用背景

在科研学术写作中，我们常常需要在 Word、Markdown 与 LaTeX 之间来回切换。虽然 Zotero 和 Better BibTeX 在 Markdown 与 $\LaTeX$   中的引用管理很顺畅，但一旦稿件进入 Microsoft Word 的审阅与修改流程，引用链接就很容易断裂。

Word 或 PDF 中的引用因此变为了“静态文本”。在反复的修改中，我们可能会删除某些正文内容，却忘了同步清理文末对应的参考文献，从而留下冗余的“幽灵文献”。
**CURE** 就是为了解决这个问题而生的。它不再依赖容易出错的软件内部链接，而是通过识别文献本身的核心语义，来帮助您自动定位并清理这些在格式转换与修改中产生的多余条目，让文献列表始终保持精准。

## 🚀 快速使用

### 环境要求

无需额外安装流程。仅需下载 `check_uncited.py` 并在 Python 3 终端环境下运行。

### 执行命令

使用命令行指定待分析的 Markdown 路径：

```bash
python3 check_uncited.py -i "manuscript.md"
```

### 可选参数

| 缩写 | 全称 | 功能描述 | 默认值 |
| :--- | :--- | :--- | :--- |
| `-i` | `--input` | **(必选)** 待处理的 Markdown 文件路径 | N/A |
| `-o` | `--output` | 校验报告导出路径 | `uncited_report.md` |
| `-h` | `--help` | 调取帮助文档 | N/A |

## 📊 核心识别机制 (Heuristic Scoring)

CURE 突破了传统的关键词搜索，采用一套**智能评分机制**来确保文献识别的准确度：
1.  **区域定位**：自动扫描全文，识别可能的参考文献标题。
2.  **内容分析**：通过评估后续文本中引用格式的分布情况，精准锁定文献列表的真正起点。
3.  **特征提取**：确认文献区域后，自动提取带有“作者姓氏 + 出版时间”的专属特征标签。
4.  **深度核对**：在正文语境中进行多行智能比对，最终确认该文献是否被真实引用。

## 📝 结果交付

程序将导出详细的 Markdown 报告 (`uncited_report.md`)，清晰罗列出所有缺乏正文支撑的文献条目，并保留原文信息供作者复核。
